# Instagram Scraper API

CoreClaw provides ready-to-use APIs for collecting structured public Instagram data.

## Supported Resources

Available tools may support:

- Profiles
- Followers-related data
- Following-related data
- Posts
- Reels
- Comments
- Business accounts
- User search

## API Benefits

- REST API
- Batch processing
- Structured JSON
- CSV export
- Managed infrastructure
- No browser maintenance
- No proxy management

## Common Integrations

CoreClaw can be used with:

- n8n
- Make
- Zapier
- Python
- JavaScript
- AI agents
- Internal SaaS workflows
