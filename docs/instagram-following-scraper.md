# Instagram Following Scraper

An Instagram following scraper helps collect public account data related to profiles followed by a selected Instagram user.

Where supported, CoreClaw can help structure public profile information for research and analysis.

## Possible Fields

- Username
- Full name
- Profile URL
- Biography
- Followers count
- Following count
- Verified status
- Business category
- External website

## Common Use Cases

- Creator-network research
- Competitor audience analysis
- Influencer discovery
- Brand relationship mapping
- Public-account research
